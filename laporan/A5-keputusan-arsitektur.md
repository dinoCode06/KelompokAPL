## 1. Ringkasan Keputusan Arsitektur

| ID | Judul ADR | Status | Keputusan Utama |
|---|---|---|---|
| ADR-001 | Arsitektur Aplikasi Web Terpusat | Accepted | Sistem layanan wisuda menggunakan aplikasi web terpusat agar mahasiswa dan admin dapat mengakses layanan melalui browser. |
| ADR-002 | Pengelolaan Data dan Verifikasi Berkas | Accepted | Data pendaftaran, dokumen persyaratan, status verifikasi, jadwal, dan pengambilan layanan dikelola melalui basis data terstruktur dengan kontrol akses. |
