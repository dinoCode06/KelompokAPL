# Bukti sumber data

Isi folder ini: ringkasan wawancara dan tangkapan layar yang dipakai sebagai sumber data.

Aturan:
1. **Tanpa identitas pribadi.** Tutup nama, stambuk, nomor telepon, dan email pada tangkapan layar.
2. Responden ditulis berdasarkan peran saja (contoh: "mahasiswa semester 5", "staf unit X"), tidak dengan nama.
3. Tidak ada data yang diambil dengan menguji keamanan sistem.
4. Satu berkas per wawancara, dengan nama `wawancara-01.md`, `wawancara-02.md`, dan seterusnya (salin dari `wawancara-templat.md`).
